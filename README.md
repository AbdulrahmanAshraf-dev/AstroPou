## 🌌 About the Project

**AstroPou** is a mobile application developed as part of **NASA Space Apps Challenge 2026 – Cairo**, by Team **Orbit Code**.

Long-duration space missions expose astronauts to unique physical, cognitive, and psychological challenges. Monitoring health and maintaining well-being throughout these missions is essential.

AstroPou aims to make astronaut health monitoring more engaging, accessible, and personal by combining health tracking, interactive visualizations, and a friendly virtual companion.

Inspired by the concept of virtual pets, AstroPou acts as an astronaut's personal health companion, helping them understand their health status, follow healthy habits, and stay motivated throughout their mission.

## 🎯 The Problem

Astronauts face several challenges during space missions:

- Changes in cardiovascular and respiratory health.
- Sleep disruption and recovery challenges.
- Physical activity and metabolic changes.
- Cognitive fatigue and reduced alertness.
- Radiation exposure monitoring.
- Isolation and emotional challenges during long-duration missions.

Traditional health dashboards may present complex information without making the experience engaging or emotionally supportive.

## 💡 Our Solution

AstroPou combines astronaut health monitoring with an interactive virtual companion.

Instead of simply presenting health metrics, AstroPou creates a more engaging experience through visual health indicators, personalized insights, and a virtual character that reacts to the astronaut's interactions and available health information.

## ✨ Key Features

### 🧑‍🚀 1. Astronaut Health Dashboard

A centralized dashboard that presents important health indicators:

- Cardiovascular health.
- Respiratory health.
- Cognitive performance.
- Physical activity.
- Sleep and recovery.
- Metabolic health.
- Radiation monitoring.

Interactive health hotspots allow astronauts to explore individual metrics and view their details.

### ⭐ 2. Ophiuchus – Astronaut Health Constellation

An interactive constellation-inspired health visualization.

- Health metrics are represented as stars.
- Selecting a star displays its corresponding health information.
- Explore health trends through historical charts.
- View metric averages, trends, and target ranges when available.

The constellation provides a space-inspired way to explore astronaut health data.

### 🐾 3. AstroPou – Interactive Virtual Companion

AstroPou is the astronaut's personal virtual health companion.

- Interactive character with idle animations.
- Contextual messages based on user interactions.
- Reactions to available health conditions.
- Friendly health reminders and encouragement.
- Metric-specific messages and feedback.

AstroPou makes health monitoring more personal and engaging.

### 💬 4. Messages & Reminders

A dedicated experience for health-related communication:

- Daily motivational messages.
- Health reminders.
- Important health alerts.
- Messages from Earth and loved ones.

### 👨‍🚀 5. Astronaut Profile

A dedicated space for astronaut profile and mission-related information.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android Emulator or a physical Android device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AstroPou.git
```

2. Navigate to the project directory:

```bash
cd AstroPou
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

### Run Tests

```bash
flutter analyze
flutter test
```
